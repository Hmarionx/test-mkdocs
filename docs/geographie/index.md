## Modèle de fiche

Pour chaque thème, une fiche reprendra :

1. **L'essentiel** en quelques lignes
2. **Définitions** des mots-clés
3. **Une étude de cas** localisée
4. **Un schéma ou une carte** à savoir commenter
5. **Pour t'entraîner** : questions avec réponses masquées
